# OntoTrace

온톨로지 기반 스마트 컨트랙트 사기 탐지 시스템입니다.

코드 취약점 탐지 도구는 많지만, 코드는 멀쩡한데 운영자가 돈을 빼 가는 러그풀 같은 사기는 잘 잡지 못합니다. 이 프로젝트는 컨트랙트의 실제 거래 흐름을 보고, 그 결과를 온톨로지 규칙으로 판정해서 왜 그렇게 판단했는지까지 보여 주는 것을 목표로 합니다.

데모: https://pb-lblockchain.vercel.app

## 어떻게 동작하나

1. 컨트랙트를 실행하면서 입금·출금 같은 거래 흐름을 수집합니다. (JavaScript 동적 분석)
2. 수집한 결과를 OWL 온톨로지의 개체로 만듭니다.
3. SWRL 규칙과 추론기(Pellet, HermiT)가 사기 유형을 판정합니다.
4. 대시보드에서 판정 결과와 근거를 보여 줍니다.

점수 하나로 잘라 말하지 않고, 어떤 조건이 맞아서 그 유형으로 분류됐는지를 규칙 단위로 보여 주는 방식입니다.

## 다루는 사기 유형

- 폰지
- 러그풀
- 자금세탁
- 펌프앤덤프

## 대시보드

개요, 거래 분석, 배포자 위험도, 상세 분석 탭으로 구성되어 있습니다. 상세 분석에서는 추론 과정과 온톨로지 구조를 확인할 수 있습니다.

배포된 데모는 미리 계산해 둔 시뮬레이션 결과를 보여 주는 시연판입니다. 실제 주소 분석은 로컬 서버로 실행할 때만 됩니다.

## 현재 상태

- 예방 레이어(사기 유형 판정): 완료
- 완화 레이어: 완료
- 배포자 위험 점수: MVP 구현 완료
- 대응 레이어: 개발 중
- 온체인 attestation(EAS, Sepolia): 구현 후 기록 확인 중
